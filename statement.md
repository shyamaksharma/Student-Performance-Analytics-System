# Student Performance Analytics System

## 1. Problem Statement

- Managing student academic information manually can make it difficult to keep student details, marks, and attendance organized.
- Student information and academic records may be stored separately.
- A simple application can be used to manage these records in one place.
- The project provides a console-based Java solution for basic student performance management and analysis.
- The system allows users to manage student records, marks, attendance, and generate individual performance reports.

## 2. Project Scope

- Student record management
  - Adding, viewing, searching, updating, and deleting
- Marks management
  - Adding and viewing marks
  - Subject-wise marks
  - Average marks
- Attendance management
  - Adding and viewing attendance
  - Subject-wise attendance
  - Average attendance
- Performance reporting
  - Individual student report
  - Student details, marks, attendance, and averages
- Data storage
  - Save and load data using local text files
- Input validation
  - Numeric input
  - Marks and attendance ranges
  - Duplicate student IDs

## 3. Target Users

- Students learning Java
- Teachers or faculty managing basic academic records
- Users who need simple student performance information

## 4. Objectives

- Apply Java concepts to a practical problem.
- Practice object-oriented programming.
- Use classes and objects.
- Use packages and ArrayList.
- Implement CRUD operations.
- Practice exception handling.
- Use Java file handling.
- Generate basic performance reports.

## 5. High-Level Features

- Student Management
- Marks Management
- Attendance Management
- Performance Reports
- File-Based Data Storage
- Input Validation
- Basic Performance Analysis

## 6. Project Limitations

- Console-based application
- Uses text files instead of a database
- Generates individual reports instead of advanced class-level analytics
- No graphical user interface

## 7. Expected Outcome

- A simple Java application for managing student academic information.
- CRUD operations for student records.
- Marks and attendance management.
- Basic student performance reports.
- Practical use of Java programming concepts.
